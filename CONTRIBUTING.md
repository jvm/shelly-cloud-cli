# Contributing

Thank you for your interest in `shelly-cloud-cli`.

At this time, this project accepts bug reports, feature requests, and security reports, but does not accept unsolicited third-party pull requests. The repository is maintained as a direct-push and tagged-release project by the maintainer; CI is optimized for `main`, scheduled security scans, and release tags rather than external pull request workflows.

## Accepted

- Bug reports through GitHub Issues
- Feature requests through GitHub Issues
- Security vulnerability reports through the process in `SECURITY.md`

## Not accepted right now

- Unsolicited pull requests
- Large refactors or feature implementations without maintainer coordination

Issues with clear reproduction steps, command output with secrets redacted, and expected behavior are appreciated.
